提醒 · 独立管理

不改变模型、Skill 或工具权限。

提醒尚未连接

会话默认不通知。在会话输入框上方开启「会话通知」后，该电脑的网页与 App 才接收该会话的提醒；关闭后不补发旧提醒。连接多台电脑时，分别保持各电脑的网页标签打开；已允许通知的标签通过浏览器通知提醒，不再显示站内任务提醒条。通知点击可打开对应会话。关闭页面后不会后台监控或推送。

外观
电脑快捷切换

保存电脑站点地址后，可从顶部名称快速切换，或在新标签页同时查看。快捷入口保存在此浏览器的当前站点，只保存名称和地址，不保存密码或授权；新电脑需在自己的站点登录。

连接与授权

凭据仅保存在此站点的 Secure / HttpOnly Cookie 中，不写入网址或本地存储。

权限边界

主会话继续由官方 Codex 桌面执行，沿用会话的工具权限和审批。移除工作区入口不等于 Codex 只读。

历史可分页读取，也可通过“我的问题”导航定位。不支持的审批仍需在官方桌面处理。
