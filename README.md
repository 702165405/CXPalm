# CXPalm

**把电脑上的 Codex，带到手机和浏览器。**

离开电脑，也能查看任务进度、继续对话、发送文件和处理审批。CXPalm 为官方 Codex
桌面提供一个由你自己管理的远程入口：电脑继续执行，手机和网页随时连接。

当前版本 **0.0.8** · Web / Android / 桌面网关 · 独立项目，非 OpenAI 官方产品。

## 为什么使用 CXPalm

- **继续同一个会话**：在手机、网页与电脑之间切换，不必复制对话，也不另开执行器接管主会话。
- **远程入口自己掌握**：网关运行在自己的电脑，域名、HTTPS 入口和连接线路由自己选择与管理。
- **访问权限可控**：账号登录、可撤销的设备授权，以及可选的 IP / 网段白名单。
- **适应自己的网络环境**：可通过自有 HTTPS 反向代理和 SSH 隧道连接，便于按国内或其他复杂网络环境选择合适的部署线路。

这里的“本地运行”指网关和会话控制运行在你的电脑上，不是本地离线模型。
模型调用、官方账号与相关服务仍由官方 Codex 客户端处理；远程访问需要电脑在线，
连接效果取决于实际网络和部署条件。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 会话管理 | 按项目分组、搜索、新建、重命名、归档与恢复 |
| 远程对话 | 发送消息、引导任务、停止、审批，以及消息排队与取消 |
| 模型与任务控制 | 模型、推理强度、Skill、权限、Plan / Goal 和上下文用量 |
| 历史阅读 | 分页历史、问题导航、共享已读、Markdown、代码与折叠工具输出 |
| 图片与文件 | 上传附件、查看会话图片与生成图片；网页支持粘贴和拖放 |
| 会话提醒 | 按会话开启任务完成、待审批提醒，默认关闭 |
| 多端连接 | 多台电脑切换、记住登录、离线只读缓存与应用内更新 |

CXPalm 是 Codex 会话的远程控制入口，不是通用远程桌面，不提供任意终端或文件浏览。

## 开始使用

1. **启动电脑端**：在自己的电脑打开官方 Codex 桌面和 CXPalm 桌面网关。
2. **配置连接**：设置自己的 HTTPS 入口；需要跨网络连接时，可使用自有反向代理与 SSH 隧道。
3. **设置账号**：在 CXPalm 桌面端创建登录账号和密码，没有默认账号或公开注册入口。
4. **连接手机或网页**：浏览器访问自己站点的 `/cxpalm/`，或在 Android App 中填写 HTTPS 地址并登录。
5. **选择会话**：继续对话、查看进度，按需开启会话提醒或配置 IP 白名单。

首次部署请参考 [部署指南](deploy/README.md) 与 [配置示例](deploy/cxpalm.example.json)。

## 部署与访问控制

电脑负责执行任务，HTTPS 入口负责将已授权的远程连接转发到本机网关：

```text
手机 / 网页 → 自有 HTTPS 入口 → 本机 CXPalm 网关 → 官方 Codex 桌面
```

- **本地监听**：网关只绑定回环地址，不直接将本机监听端口暴露到公网。
- **自主部署**：远程代理和隧道由自己配置；不要求把远程控制交给额外的公共托管平台。
- **设备授权**：可在桌面端撤销设备；更改登录账号密码会撤销已有登录授权。
- **可选白名单**：限制允许访问的 IP 或网段，只作用于 CXPalm API，不修改系统防火墙。隧道模式须先配置可信代理的真实 IP 转发。

请妥善保护自己的服务器、登录凭据和设备。具体信任边界见 [安全说明](SECURITY.md)。

## 更新与维护

Android 与桌面端从本仓库的更新清单检查版本，并从 [GitHub Releases](https://github.com/702165405/CXPalm/releases)
下载安装包，由用户确认安装；网页更新由部署者发布。更新会校验下载来源、文件哈希及应用身份，
只允许当前仓库的发布路径和对应 GitHub 下载服务跳转。自建分发需配置自己的仓库更新源，
与登录服务器地址分开管理，详见 [部署指南](deploy/README.md)。

版本变化见 [变更记录](CHANGELOG.md)。反馈问题时请提供版本、操作系统与复现步骤，
不要附带登录凭据、真实聊天内容或完整运行日志。构建、测试和贡献方式见 [贡献指南](CONTRIBUTING.md)。

CXPalm 依赖官方桌面的会话接口，官方客户端升级可能需要适配。浏览器关闭或手机
系统停止后台进程后，提醒不保证送达；使用边界与验证状态见相关文档。
