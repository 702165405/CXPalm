CXPalm 0.0.19 / build55: Add session-scoped approval. When the original owner request explicitly offers persistence for the current conversation, Web and Android can approve for this session and the owner stores the scoped grant; command and file approvals require acceptForSession in availableDecisions, MCP tool confirmations require _meta.persist to offer session, permission-profile requests stay turn-only, and permanent always grants are never exposed. Both clients confirm the scope before sending and the gateway caches nothing globally. Also keep normal Web and Android conversations usable when the desktop does not expose a verifiable identity: report cross-device read synchronization and per-chat notifications as temporarily unavailable instead of repeatedly surfacing read identity errors, never guess historical accounts, create auth files, mark unconfirmed replies read or replay a previous account's notifications, and restore optional features when identity returns while preserving saved settings, authorization and IP policy. Safe degradation only, not a replacement desktop login or physical-device acceptance.
