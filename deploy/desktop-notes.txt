CXPalm 0.0.3 / build3: Web and Android now display conversation errors beside the corresponding turn instead of silently dropping them. Includes tool error messages, read-only historical error events and explicit fallback notices when the desktop supplies no detailed failure reason. Error cards are visible without expanding tool output, rendered as bounded plain text with common credentials and URLs redacted. No automatic retry, message replay or execution-owner change. Existing configuration, device authorization and startup preferences are preserved.
